# 范围容量不足时原子失败而不自动降级

范围准备若超过受支持的文本快照数、不透明身份数、session 总字节数或其他必要的有界持久化容量，整次范围切换失败并保留上一有效范围。DiffTracker 不自动把文本降级为 opaque、不淘汰最旧或最大的基线、不只保存能放下的部分，也不在容量不完整时显示全工作区已生效；用户可增加显式排除、回到规则模式或在未来版本采用经测量调整后的新界限。

范围预检可以提前警告预计容量风险，但正式结果以完整候选状态能否通过 schema 校验并可靠持久化为准。容量界限可以在 S0/S4 基于 0.7.2 的实际测量调整或按类别拆分，但必须保持有界，并为失败、恢复和兼容性提供明确测试。

# 保持精确且不可覆盖的不可监控资源边界

0.8.0 将以下资源定义为不可监控：非 `file:` 资源；不属于本地工作区根严格后代的路径；任一路径组件为符号链接的资源；任一名为 `.git` 的路径组件及其后代；任一名为 `.difftracker-restore-*` 的目录及其后代。该边界在规则模式、全工作区模式、显式包含和显式排除迁移期间都不可覆盖。

`.git` 边界包括普通仓库元数据目录、linked worktree 的 `.git` 文件和嵌套 `.git` 名称，但不包括 `.gitignore`、`.gitattributes` 或 `.gitmodules`。所有 symlink 路径保持不可监控，即使其真实目标仍在工作区内；0.8.0 不引入链接别名、目标身份或 watcher 跟随模型。`.difftracker-restore-*` 前缀由扩展保留，Extension Host 崩溃后遗留的目录仍不进入监控，也不由扩展递归删除；界面可以提示用户人工检查和清理。

依赖、构建输出、缓存、秘密或其他普通工作区文件不因名称自动成为不可监控资源。它们是否进入范围由模式和显式排除决定。

# 全工作区范围准备采用有界预检而不设固定拒绝阈值

全工作区模式在正式范围扩展前进行有界预检，给出资源数量和体量的估计或“至少 N”的下界，标示估算是否截断，并提示已发现的依赖、构建和覆盖率等高负载目录。预检不读取完整文件内容、不计算全部 hash、不作为基线，也不自动生成排除项；失败时显示规模未知，仍允许用户选择继续、编辑排除或取消。高负载警告只帮助用户判断，不把这些目录偷偷排除。

不设置跨项目通用的固定文件数或容量拒绝上限：用户确认后可尝试准备，但过程必须可取消，读取并发、事件证据与监听资源受界限约束，大文件流式处理，并受现有 session 大小与可靠持久化要求限制。达到真实资源上限或无法保存完整必要证据时，范围切换失败并保持上一有效范围，不静默丢弃资源、不自动退回规则模式、不以局部完成冒充全工作区生效。

准备界面显示阶段、当前工作区根、已检查资源数、待核验数与覆盖问题数，不滚动显示完整敏感路径或记录所有路径日志。扫描期间的事件按路径合并为足以保留不稳定证据的状态：少量不稳定路径标记为待审或未知，不阻止其余稳定资源完成；若事件量超过证据的有界容量，使变化无法可靠保留，则整个范围切换失败并报告“准备期间变化过多”，待用户稳定工作区后手动重试。任何失败或取消都不能把未观察到的活动伪装为已核验的无变化。

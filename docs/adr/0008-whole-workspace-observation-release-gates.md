# 以真实宿主覆盖能力作为全工作区模式的发布门

0.8.0 发布候选必须在真实 Extension Host 中证明受支持本地工作区的普通路径、Git 忽略路径和代表性 `files.watcherExclude` 目录可以在全工作区模式下捕获文本与非文本的新增、修改和删除。验收还包括嵌套目录、范围切换、VS Code 重载、覆盖失败、重新检查和盲区核对；按仓库现有 CI 适用范围覆盖 Linux、Windows、Stable Host 和最低支持版本 Host。Mock 测试用于竞态和故障注入，不能替代真实 watcher 行为。

普通支持场景静默漏记、把覆盖缺口显示为无变化、重启后直接复用旧覆盖结论、或 watcher 恢复后不核对盲区，均属于发布阻塞。用户文件权限、系统 watcher 配额或宿主平台限制可以作为“覆盖受限”而不阻止发布，但前提是产品准确定位受影响子树、保留未知状态、提供重新检查入口，并且不以此掩盖基本实现缺失。

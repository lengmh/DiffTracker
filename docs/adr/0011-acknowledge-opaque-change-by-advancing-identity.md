# 通过推进身份确认不透明变化

确认不透明变化时，DiffTracker 重新核验资源当前存在性和内容身份，并仅在 review token、范围配置版本、session epoch、Git 上下文和覆盖证据仍有效且新状态成功持久化后，将其推进为新的不透明审阅基线。确认期间资源再次变化、保存失败、dirty editor、扫描不确定性或覆盖缺口都会阻止旧确认清除新的待审状态。

该动作不写入、删除或恢复工作区文件，不复制非文本内容，也不创建非文本 Undo。确认删除表示当前不存在状态已被确认；确认新增或修改表示当前身份成为已确认存在的基线。证据不足的活动提示不能被强确认伪造成可靠身份；弱“已阅活动”若未来实现，必须作为不同语义，不是 0.8.0 的必要能力。
